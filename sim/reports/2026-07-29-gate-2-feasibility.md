# 《反擊超載》Gate 2 可行性模擬

日期：2026-07-29  
固定 seed：`counter-overdrive-gate-2-v1`  
局數：30,000

## 結論

第二輪模型通過 Gate 2 的數值結構門檻，可交由人類決定是否簽核設計。

通過只代表：

- 四個核心家族都有數學上的完整 run 勝法；
- 沒有單一核心或被動在勝場中壟斷；
- 維持高威脅確實能縮短戰鬥；
- 同 seed 重跑摘要完全一致。

不代表四方向反擊好玩、450ms 前搖公平、聲光加速清楚。這些只能在 Gate 3 灰盒中驗證。

## 第一次模型為何失敗

初始 Boss 崩解值為 78–145，玩家完整度 5。30,000 局結果：

| 指標 | 初始模型 |
|---|---:|
| 完整 run 勝率 | 2.31% |
| 平均通過 Boss | 1.26／6 |
| 返擊鏈勝率 | 5.56% |
| 飛輪勝率 | 0.87% |
| 洩壓勝率 | 1.17% |
| 相位勝率 | 1.57% |

問題不是玩家精準度，而是 Boss 耐久要求玩家長時間維持完美反擊；返擊鏈又因直接傷害核心形成明顯支配。該版不能進 Gate 2。

## 修訂

1. Boss 崩解值收斂為 60、68、78、88、100、118。
2. 玩家每場完整度由 5 調為 6。
3. 返擊鏈核心直接傷害由 10 降為 7。
4. 飛輪、洩壓、相位核心各取得 5–6 點功能性反擊傷害，避免只有返擊鏈能通過後段耐久檢查。
5. 洩壓家族在威脅 3 即主動兌現，明確形成「較慢但穩定」的比較組；飛輪則保留高威脅。

## 最終結果

| 指標 | 結果 | 門檻 | 判定 |
|---|---:|---:|---|
| 完整 run 勝率 | 27.52% | 25–45% | 通過 |
| 平均通過 Boss | 3.32／6 | 觀察值 | — |
| 家族最高／最低勝率差 | 12.55pp | ≤15pp | 通過 |
| 最大勝場核心占比 | 28.64% | ≤35% | 通過 |
| 最低勝場被動出現率 | 28.88% | ≥5% | 通過 |
| 前五完整 build 勝場占比 | 2.48% | ≤40% | 通過 |
| 高威脅飛輪相對安全洩壓的清場時間 | 快 15.42% | ≥12% | 通過 |

### 家族結果

| 家族 | 勝率 | 勝場核心占比 | 勝利 run 平均攻擊數 | 模型平均清場時間 |
|---|---:|---:|---:|---:|
| 返擊鏈 | 31.15% | 28.64% | 75.42 | 56.44 秒 |
| 飛輪 | 21.18% | 19.22% | 79.27 | 54.82 秒 |
| 洩壓 | 27.05% | 24.32% | 78.95 | 64.82 秒 |
| 相位 | 30.63% | 27.81% | 77.01 | 55.85 秒 |

飛輪勝率較低但速度最快，洩壓較慢但勝率高出 5.87pp，形成可解釋的風險／報酬差異。返擊鏈仍是最高勝率，但沒有超過 35% 核心占比或 15pp 家族差距門檻。

## 決定性

`sim/prototype.test.ts` 會用同一 seed 重跑兩次並比較完整摘要。30,000 局報告另保留前 32 局的摘要 digest；同一版本重跑完全一致。

執行：

```bash
pnpm sim:gate2
pnpm test
```

## Balance Engineer 建議

- Gate 3 不要先調低 450ms 最短前搖；若玩家覺得不刺激，優先加強聲光、命中停頓與連擊編排。
- 灰盒需分別測 60Hz 鍵盤與常見筆電鍵盤，記錄普通、完美、錯誤方向與逾時比例。
- 若實測中返擊鏈仍明顯最容易，先把「裂解核心」兌現傷害由 7 降至 6，不調低所有完美反擊傷害。
- 若洩壓感覺拖沓，應改善核心釋放表現或把冷卻空窗做成可主動進攻的段落，不直接提高固定傷害。
