# 《反擊超載》0.4.0 正式遊戲規格：固定譜面／分數擊破

狀態：`design_ready`

日期：2026-07-29

Scope：small；單局目標：4–5 分鐘

## 一句話

在開場即鎖定的三軌譜面上，用 `←`、`→`、`Space` 演奏整首 Boss 樂句；命中累積擊破分數，流派決定哪些既有音符更有價值、哪些窗口更可靠，以及如何把擊破後的尾奏轉成額外分數。

## 此次 Pivot 解決的問題

0.3.x 以動態崩解值結束戰鬥。Boss 死亡時為了避免多餘音符而壓縮、移除或置換目標，造成譜面跳動與結局突兀；構築又以改寫音符呈現，令玩家在演奏途中必須在中央譜面與外圍戰鬥概念間切換注意力。

0.4.0 的不可妥協原則：**一場戰鬥的每個可打音符，都在倒數開始前確定；其後不得新增、刪除、替換、壓縮、重排或改變任何音符的時間與鍵位。**

## 核心循環

1. 進戰前，seed、已選核心、模組與路線只用來從合格模板排列出一張完整譜面。系統先驗證精確音符數與教學語法，才允許倒數。
2. 每個原生音符：Perfect = 2 分、普通 = 1 分、Miss = 0 分。Boss 分數到達擊破門檻時立刻進入「加分尾奏」，但譜面繼續至最後一顆。
3. 核心、模組與路線讓既有序列產生額外分數、窗口、保險或連段決策；所有觸發痕跡直接貼在該既有音符上。完整演奏後，額外分數決定本戰評價與 Run 結算品質。

## 三鍵與共用節拍軸

| `KeyboardEvent.code` | 動作 | 語意 |
|---|---|---|
| `ArrowLeft` | 左軌反擊 | 僅處理左軌既有目標 |
| `ArrowRight` | 右軌反擊 | 僅處理右軌既有目標 |
| `Space` | 中央重拍 | 僅處理中央既有目標 |

- 不支援 WASD、上下、Shift、組合鍵、長按或雙擊；輸入只用 `event.code`，輸入法組字期間不判定。
- 音樂、譜面、預告、判定與視覺共用同一個 transport；`requestAnimationFrame` 只負責呈現。
- 同一音符只接受一次輸入；錯軌消耗該音符。相鄰音符依最近目標優先，且各音符在出現時固定自己的視覺槽位。
- 玩家輸入的首發聲音必須在按鍵當下播放，不能延遲吸附至理論拍點。

## 固定譜面契約

`content/rhythm-patterns.json` 仍是唯一節奏模板來源，`content/bosses.json` 的 `fixed_chart` 是每戰完成契約。

1. 在倒數前，`compileFixedChart(seed, encounter, route, build)` 必須選出完整模板序列，展平成有序 `ChartNote[]`。
2. 編譯結果必須恰好等於 `fixed_chart.note_budget`，小節數恰好等於 `fixed_chart.chart_bars`，包含所有教學、路線語法與紅線句。任一不符即視為內容錯誤，不可以 runtime 補音或刪音修正。
3. `ChartNote` 的 `id`、`targetTime`、`lane`、`barIndex`、`patternId` 與預先配置的顯示槽位一經建立即不可變。只可附加非判讀性視覺與分數狀態。
4. seed、選擇與譜面編譯結果必須在倒數前記錄於 run replay；同一輸入紀錄必須得到完全一致的判定與分數。
5. 最後一顆音符結束前不可顯示結算、切走音樂、清空目標或進入新選擇。最後一顆結算後，才播放終曲小節並切換。

### 三戰固定預算

| 戰鬥 | Boss | BPM | 小節 | 固定音符 | 基礎滿分 | 擊破門檻 |
|---|---|---:|---:|---:|---:|---:|
| 1 | 雙軌校準者 | 120 | 22 | 50 | 100 | 36 |
| 2 | 重拍執行官 | 132 | 28 | 72 | 144 | 62 |
| 3 | 核心監督者 | 144 | 34 | 96 | 192 | 92 |

- 擊破門檻不是血量回扣：分數只會增加，Miss 永遠是 0 分，絕不倒扣擊破進度。
- 基礎滿分只計音符本身；核心／模組提供的額外分數計入 `bonusScore`，可使總分超出基礎滿分。
- 戰鬥 HUD 固定同時顯示 `擊破分數／門檻`、`樂句 已演奏／固定音符`、`額外分數`。不得以未知 Boss 血量代替。

### 擊破與加分尾奏

- `score >= defeat_score` 的當下：Boss 顯示「擊破」，音樂進入較強的勝利配器，HUD 顯示「加分尾奏」與剩餘音符數。
- 當前已生成的譜面完全不變，所有剩餘音符仍照常出現、判定、發聲與計分。
- 進入加分尾奏後，Miss 不再扣除玩家完整度、不會造成死亡，也不會倒扣分數；它仍記入準度、斷開一般連段並產生低通回饋。
- 流派觸發與額外分數在尾奏繼續有效；尾奏的目的不是等待，而是將擊破後剩餘樂句演奏成分數上限。
- 只有最後一顆音符的普通／Perfect／Miss 已結算後，才開始一個完整終曲小節與下一個覆蓋層。若擊破門檻直到最後一顆才達成，仍先結算該顆，再進終曲。

## 節奏難度與內容邊界

| 戰鬥 | Perfect 窗口 | 普通窗口 | 內容上限 |
|---|---:|---:|---|
| 戰 1 | ±60ms | ±140ms | 左右四分與交替；僅使用有休止分隔的短八分二連，不使用 Space、切分、同側壓力 |
| 戰 2 | ±50ms | ±120ms | 中央重拍、同側二連、每小節最多一組八分二連；不使用切分 |
| 戰 3 | ±45ms | ±100ms | 三軌、八分鏈或切分的路線深化；每拍最多兩目標，連續八分最多四顆 |

- 第一次出現的語法必須完整預覽；預告後不可改鍵、改拍或縮短。
- 戰 2 的路線決定整張待編譯譜面的模板權重，但在倒數後不能改寫譜面。
- 超載仍為 0–5 的配器與加分狀態，不得加入、刪除或改變既有目標；紅線句必須在編譯時已存在於固定譜面。

## Rogue 構築：改變演奏價值，不改變譜面

每張卡的資料契約由 `content/items.json` 的 `score_preview` 提供：

- `sequence`：四格既有範例音符，永遠不表示會被生成、插入或重寫。
- `operation`：唯一允許 `←`、`→`、`Space`、`無需按鍵`。
- `central_cue`、`payoff`、`cost`：貼在既有音符上的提示與取捨。

| 構築 | 對固定譜面的實際影響 |
|---|---|
| 交叉共振 | 原生左右交替皆 Perfect，第二拍 +2 分 |
| 重拍電容 | 原生中央 Perfect 蓄能；下一個原生中央 Perfect 每層 +2 分，最多 2 層 |
| 穩態飛輪 | 每小節第一次普通保連段；下一個既有小節全 Perfect +4 分 |
| 交叉導體 | 相反側既有下一目標普通窗 +40ms |
| 同側棘輪 | 同側二連第二拍 Perfect 窗 -20ms，成功 +2 分 |
| 空拍保險 | 原生中央 Perfect 裝填一次保險；下一 Miss 改普通，該小節不拿流派額外分數 |
| 三相序列 | 原生 `左→右→中央` 或反向全 Perfect，中央拍 +4 分 |
| 延遲簧片 | 原生切分目標在 Perfect 窗後半命中，該拍 +2 分，每小節最多 2 次 |
| 斷路器 | Miss 後保護下一段既有兩音符不扣完整度，每戰最多 2 次，該小節不拿流派額外分數 |

- 這些效果不得生成新的 `ChartNote`、轉換休止格、取代下一小節、壓縮終結樂句，或直接造成 Boss 傷害。
- 所有觸發只以目標邊框、導線、分數徽記、窗口環、電荷或護盾附著在既有音符上；HUD 只能是摘要。
- 選核心、草稿、路線時以同一條固定四格樂句展示「哪個既有音符更值錢／更安全」，而不是「譜面會被改成什麼」。選擇後可進行無傷害四拍實演，但實演不等於正式譜面。

## Run 結構與路線

```text
選 1 起始核心 → 戰 1 固定譜面 → 選 1 模組 → 選路線
→ 戰 2 固定譜面 → 選 1 模組 → 戰 3 固定譜面 → 結算
```

- 每局為 1 核心、最多 2 被動。路線公開下一戰的語法傾向與加分家族，不公開精確模板順序。
- 路線、核心、被動可以改變「倒數前編譯時選到哪張完整合法譜面」，但不能在演奏中改變該張譜面。
- 死亡清空本局構築與進度；進入加分尾奏後不會因 Miss 死亡。

## 單畫面與終局呈現

- 1280 × 720 單畫面固定看見三軌、未來一小節、擊破分數、樂句進度、額外分數、完整度、超載與已持有構築；不需滾動。
- 不用飛行箭頭表示鍵位。近距同軌音符的水平槽位由編譯時索引固定，任一音符消失不得造成其他音符跳位。
- 到門檻時不清空目標。Boss 視覺可以改為崩解／發光，但中央軌道保持完整至曲末；結果畫面禁止在最後音符前覆蓋。
- 終曲使用完整收束小節，且只能在譜面已完全結算後排程。

## Gate 2／Gate 3 新增驗收

- 30,000 局模型中，每個 encounter 的 `ChartNote.length` 精確為 50／72／96；任何 seed 不得發生 runtime 補音、刪音、改鍵、改拍或順序變動。
- 使用相同 seed、選擇與輸入紀錄，在「門檻前」與「門檻後」皆得到完全一致的剩餘 note list；門檻只能改變 `postDefeat` 狀態與音樂／視覺層。
- Perfect／Normal／Miss 分別精確給 2／1／0 基礎分；Miss 永不倒扣擊破分數。
- 達門檻後，剩餘每個音符仍被呈現與判定一次；其 Miss 不扣完整度、不造成死亡，且完整譜面結束後才進終曲。
- 三核心與六個被動都有可觀測的分數、窗口或保險觸發；沒有任何效果變更 `ChartNote` 數量、時間或鍵位。
- Gate 3 至少 70% 受測者能回答：目前距離擊破還差幾分、還剩幾顆音符，以及自己選的構築讓哪一種既有音符更有價值。

## 範圍排除

- 不做動態 Boss 血量壓縮、終結樂句替換、演奏中生成／刪除音符、第四鍵、商店、永久成長、觸控、排行或多人。
- 不用純固定傷害替代構築；額外分數必須綁定可辨識的原生節奏條件、窗口或失誤取捨。
