# 反擊超載

反擊愈準，世界愈快。

## 0.1.1 垂直切片

- `W/A/S/D` 或方向鍵：對應四方向反擊
- `Shift`：相位穿越紅色破防招
- `Space`：威脅達 3 後釋放制動核心
- 完美反擊會提高威脅，讓攻擊從 900ms 逐步加速至 450ms
- 一隻完整 Boss「棱鏡監工」，包含直擊、雙脈衝、回返、破防與吸能
- 攻擊移動改用無方向能量脈衝，中央固定高亮應按的 `W/A/S/D`，避免箭頭與按鍵方向相反
- `1280 × 720` 單畫面，玩家可見遊戲術語使用繁體中文

## 開發

```bash
pnpm install
pnpm dev
pnpm verify
```

遊戲代號：`counter-overdrive`
