# 反擊超載

在與音樂共用的三軌節拍上，以左、右與中央重拍接住 Boss 樂句；戰後選擇會改寫下一戰的節奏規則，形成本局專屬的反擊流派。

## 0.4.4 固定譜面 Rogue Run

- `ArrowLeft`：左軌反擊
- `ArrowRight`：右軌反擊
- `Space`：只對公開的中央重拍／紅色破防生效
- 戰 1 為 120 BPM，只教左右與交替
- 戰 2 為 132 BPM，加入中央重拍、同側二連與路線樂句
- 戰 3 為 144 BPM，加入八分鏈、切分與紅線小節
- 完整流程：選 1 核心 → 戰 1 → 三選一 → 二選一路線 → 戰 2 → 三選一 → 戰 3 → Run 結算
- 3 個起始核心與 6 個被動模組全部以被動、自動或公開節拍條件觸發
- 攻擊、判定、視覺與音樂共用 performance/audio timeline；畫面幀率不決定判定
- 使用 `KeyboardEvent.code`，繁體中文輸入法開啟時不必切換英文
- 音樂、效果、介面三組音量及全域靜音
- `1280 × 720` 單畫面，戰鬥、草稿、路線與結算都不需要捲動
- 每戰倒數前便鎖定完整譜面：Perfect 2 分、普通 1 分、Miss 0 分；達成擊破門檻後，所有剩餘音符仍完整演奏為「加分尾奏」
- 加分尾奏的失誤不扣完整度或倒扣分數；最後一顆音符結算後才播放終曲並進入選擇／結果
- 所有核心、模組與路線先顯示四格既有樂句的「加分／窗口／保險」效果；構築直接標記在中央三軌既有目標上，但不改寫正式譜面
- 八分連打在判定交界時優先交給較近的下一個目標；同軌近距音符會展開並標示連打順序
- 近距音符的橫向槽位在出現後固定，消除前一顆不會讓其餘音符跳位；提供預設關閉的「測試用・自動點擊」Perfect 測試開關，可穩定完成每一場戰鬥，但保留核心、模組與路線的手動選擇
- 擊破不會壓縮終結樂句、置換或消除任何音符；曲末永遠是固定譜面的最後一顆
- 固定音符數不變，關卡時長縮短約 30%；連打反擊回饋可累積顯示，背景節拍會在每個可打音符格點提供重音
- 方塊以「中心對準反擊線」判定 Perfect；每軌有準星與接近／對齊提示，視覺錨點與實際判定一致
- 方塊下方的小標不再影響幾何定位；中央橘色準星與三軌使用同一欄位 Grid，保證居中
- 切分頁安全暫停後會自動恢復；若瀏覽器阻擋背景音訊恢復，畫面會顯示「繼續演奏」按鈕，不會停在無音樂、無後續音符的死狀態

目前聲音採 Hybrid 方案：原創程序式 Web Audio 配樂、節拍與戰鬥音效，保留後續替換正式 Stem／sample 的事件介面。
