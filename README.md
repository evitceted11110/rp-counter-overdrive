# 反擊超載

反擊愈準，世界愈快。

## 0.2.1 背景音樂版

- `W/A/S/D` 或方向鍵：對應四方向反擊
- `Shift`：相位穿越紅色破防招
- `Space`：威脅達 3 後釋放制動核心
- 完美反擊會提高威脅，讓攻擊從 900ms 逐步加速至 450ms
- 一隻完整 Boss「棱鏡監工」，包含直擊、雙脈衝、回返、破防與吸能
- 攻擊移動改用無方向能量脈衝，中央固定高亮應按的 `W/A/S/D`，避免箭頭與按鍵方向相反
- 動態配樂依威脅階級從 96 BPM 提升至 166 BPM，逐層加入主拍、切分、低音與琶音
- 原創 D 小調背景曲使用四小節和聲循環、低音主題與旋律動機，低威脅時也能聽見完整樂曲
- 攻擊與反擊發生時會自動短暫壓低背景樂，保留關鍵讀招音效空間
- 四向攻擊具有方向聲像／音色提示；破防、完美反擊、相位、失誤與制動核心各有獨立聲音輪廓
- 音樂、效果、介面三組音量與全域靜音可在單畫面浮層內調整
- `1280 × 720` 單畫面，玩家可見遊戲術語使用繁體中文

## 開發

```bash
pnpm install
pnpm dev
pnpm verify
```
