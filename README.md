# 反擊超載

在與音樂共用的三軌節拍上，以左、右與中央重拍接住 Boss 樂句；戰後選擇會改寫下一戰的節奏規則，形成本局專屬的反擊流派。

## 0.3.2 三軌 Rogue Run

- `ArrowLeft`：左軌反擊
- `ArrowRight`：右軌反擊
- `Space`：只對公開的中央重拍／紅色破防生效
- 戰 1 為 120 BPM，只教左右與交替
- 戰 2 為 132 BPM，加入中央重拍、同側二連與路線樂句
- 戰 3 為 144 BPM，加入八分鏈、切分與紅線小節
- 完整流程：選 1 核心 → 戰 1 → 三選一 → 二選一路線 → 戰 2 → 三選一 → 戰 3 → Run 結算
- 3 個起始核心與 6 個被動模組全部以被動、自動或公開節拍條件觸發
- 攻擊、判定、視覺與音樂共用 performance/audio timeline；畫面幀率不決定判定
- 使用 `KeyboardEvent.code`，繁體中文輸入法開啟時不必切換英文
- 音樂、效果、介面三組音量及全域靜音
- `1280 × 720` 單畫面，戰鬥、草稿、路線與結算都不需要捲動
- Boss 擊破後會停止後續音符，完成一個明確的終曲小節後才進入下一次選擇或結算
- 所有核心、模組與路線先顯示四格「原句 → 改寫 → 操作」；構築效果直接標記在中央三軌目標上
- 八分連打在判定交界時優先交給較近的下一個目標；同軌近距音符會展開並標示連打順序

目前聲音採 Hybrid 方案：原創程序式 Web Audio 配樂、節拍與戰鬥音效，保留後續替換正式 Stem／sample 的事件介面。
